# Cambridge City FC — Official Team App

The Lilywhites · NPL Midlands Division · FWD-IP Community Stadium, Sawston

## Deploy to Vercel

1. Create a GitHub repo called `cambridge-city-fc`
2. Upload all files from this zip into the repo and commit
3. Go to vercel.com → Add New Project → Import the repo → Deploy
4. Share the live URL with your squad

## Local development
```
npm install
npm run dev
```
